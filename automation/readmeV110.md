An **Enterprise AI Tutor** built with **Python** and **Streamlit** that combines AI-powered learning, Retrieval-Augmented Generation (RAG), workflow automation, and enterprise-grade architecture into a single platform.

---

## ✨ Features

- 🤖 Multiple AI Providers (Ollama, OpenAI, Anthropic)
- 📚 AI Tutor & Interactive Learning
- 📄 PDF Tutor
- 📝 AI Notes Generator
- ❓ Quiz Generator
- 🗂️ Flashcards
- 📅 Study Planner
- 🌐 Translation Support
- 🔍 RAG (Retrieval-Augmented Generation)
- ⚙️ Workflow Automation Engine
- 🎨 Workflow Designer
- 🔌 Plugin System
- 📊 Monitoring Dashboard
- 🎨 Modern Streamlit UI

---

## 🛠️ Technology Stack

- Python
- Streamlit
- Ollama
- OpenAI API
- Anthropic API
- MySQL
- RAG
- GitHub

---

## 🚀 Installation

```bash
git clone https://github.com/satya66123/AI-Tutor.git

cd AI-Tutor

pip install -r requirements.txt

streamlit run app.py
```
