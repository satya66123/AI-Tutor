# 📖 Overview

We welcome contributions from developers, students, educators, and AI enthusiasts. Every contribution helps improve Enterprise AI Tutor and benefits the community.

---

# 🚀 Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Optimizing existing code
- Adding new AI providers
- Improving UI/UX
- Writing tests
- Fixing issues

---

# 📋 Prerequisites

Before contributing, ensure you have:

- Python 3.12+
- Git
- MySQL
- Ollama (Optional)
- A GitHub Account

---

# 🍴 Fork the Repository

Fork the repository to your GitHub account.

```bash
git clone https://github.com/YOUR_USERNAME/AI-Tutor.git

cd AI-Tutor
```

---

# 🌿 Create a Branch

Create a new branch for your feature or fix.

```bash
git checkout -b feature/your-feature-name
```

Examples

```text
feature/voice-ai

feature/new-provider

bugfix/chat-history

docs/readme-update
```

---

# 💻 Make Changes

Follow the project coding standards.

- Write clean code
- Keep functions modular
- Use meaningful names
- Add comments where necessary
- Follow the existing project structure

---

# ✅ Test Your Changes

Before submitting your changes:

- Verify the application starts successfully
- Test your feature
- Ensure existing functionality is not affected

---

# 📝 Commit Changes

Use clear commit messages.

Examples

```bash
git commit -m "Add Voice Analytics"

git commit -m "Improve RAG Search"

git commit -m "Fix Chat History Bug"
```

---

# 📤 Push Changes

```bash
git push origin feature/your-feature-name
```

---

# 🔀 Create a Pull Request

After pushing your changes:

1. Open GitHub
2. Create a Pull Request
3. Describe your changes
4. Submit for review

---

# 📏 Coding Guidelines

- Follow PEP 8
- Keep functions small
- Avoid duplicate code
- Write readable code
- Use meaningful variable names
- Handle exceptions properly

---

# 📚 Documentation Guidelines

When updating documentation:

- Use Markdown
- Keep formatting consistent
- Add examples where appropriate
- Update related documents if necessary

---

# 🐞 Reporting Issues

When reporting an issue, include:

- Operating System
- Python Version
- Error Message
- Steps to Reproduce
- Expected Behavior
- Screenshots (if applicable)

---

# 💡 Feature Requests

Feature requests should include:

- Feature Description
- Use Case
- Benefits
- Proposed Solution

---

# 📜 Code of Conduct

Please be respectful and professional.

- Be kind
- Be constructive
- Respect all contributors
- Encourage collaboration

---
