# 📖 Overview

This guide explains how to use all the major features of the Enterprise AI Tutor application.

---

# 🚀 Getting Started

Launch the application.

```bash
streamlit run app.py
```

Open your browser.

```
http://localhost:8501
```

---

# 🏠 Dashboard

The Dashboard is the home page of the application.

### Features

- Learning Overview
- Quick Navigation
- Recent Activities
- AI Usage Statistics
- Voice Statistics
- Learning Progress

---

# 🎓 AI Tutor

The AI Tutor helps users learn through intelligent conversations.

### Steps

1. Open **AI Tutor**
2. Select an AI Provider
3. Choose a Model
4. Enter your question
5. Click **Send**
6. View the AI response

---

# 🤖 Select AI Provider

Choose one of the available providers.

- Ollama
- OpenAI
- Anthropic

After selecting the provider, choose an available model.

---

# 📚 Enterprise RAG

Ask questions based on your uploaded documents.

### Steps

1. Open **Enterprise RAG**
2. Upload a document
3. Wait for indexing
4. Ask a question
5. View the generated answer

---
